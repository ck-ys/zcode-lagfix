# v0.4.4

日期：2026-11-14
主题：切换会话后的回填大页实验（默认关闭）+ 只读补页行数归因。

## 新增

- **切换后大页补页（`switchBackfillPageOn`，默认关闭，实验）**：真实会话切换后的 30 秒内，把无参 `loadOlder()` 的页大小从宿主默认 60 行提到 120 行（协议上限 200），用更少的调用与中间提交完成同一段历史回填。
  - 只在真实会话之间切换后生效；首次挂载、同一会话重挂、`draft`/空 sid 不新开窗口；从真实会话切到占位会话时清掉旧窗口。
  - 窗口 30 秒；已载行数 >3000、行数不可读、窗口过期或调用方显式传参（含 `undefined`）时原样直通，不猜参数。
  - 不跳过、不合并、不缓存、不预取、不删除、不改顺序；保留 `this`、返回的原 Promise 引用、同步异常、`loadingOlder` / `canLoadOlder` 与返回内容。
  - 只包当前主 store 实例，不碰共享原型；包装安装条件扩展为 `scrollDiagOn || loadOlderPaceOn || switchBackfillPageOn`，只开本项也能生效。
  - 与「大会话翻页降频」独立：降频先决定是否调用，本项只决定调用时的页大小；被降频跳过的调用不消耗本项计数。
- **补页行数归因（只读）**：切换记录新增 `loadOlderRows30s`，只累加成功补页实际增加的行数，用于按每 1000 行归一化 A/B；坏数字按 0，不猜。
- **样本与报告**：样本新增 `switchPage={limit:120,applied,passthrough,installed}`；`/lagfix report` 新增「切换回填页（实验）」段，按「按 120 请求 / 按原样」显示，并在行首标出最新样本所在窗口；切换段每条 30 秒补页显示 `N 次 / R 行 / Xms`（旧样本无 R 显示 `-`）。
- 面板「性能 → 实验」新增「切换后大页补页 · 实验」，默认不勾选；文案按「会做什么 / 不会做什么 / 代价」说明。

## 修复

- **滚动诊断关闭再打开后，保留下来的 `loadOlder` 包装观测不恢复**：诊断代际原先在包装创建时捕获，关闭诊断会让代际 +1；当包装因降频或本实验继续保留时，重新打开诊断后旧包装的回调永远失配，补页明细/耗时不再记录。现在每次观测调用开始时取当前代际，关闭前已在途的调用仍然作废，重新打开后的新调用正常记录。

## 安装注意

- 本版新增设置键 `switchBackfillPageOn`（默认关闭，实验）；不改变任何既有默认值，`loadOlderPaceOn` 仍默认关闭。
- 仍需通过源码安装器或插件市场安装；安装会修改 `app.asar`，成功后必须**完全退出**并重新打开 ZCode（仅关闭窗口不算）。
- 不读写 `~/.zcode/cli/db.sqlite`，不读会话正文，不打开 CDP，不联网上报；网络请求仍只有用户手动或可选自动检查公开 GitHub Releases。

新增/更新断言覆盖：

- 默认关闭、样本 `switchPage=null`、无参调用不传页大小；
- 真实切换后无参补页收到 `[120]`、返回原 Promise、按 120 请求计数 +1；
- 显式 `60` / `200` / `undefined` 原样直通且不计入 `applied/passthrough`；
- 30 秒窗口过期、行数 >3000、行数不可读、`draft`/空 sid 均直通；
- 只开本项、关滚动诊断时包装仍安装并生效；与 O3 组合时跳过不调用原方法、不计页计数；
- 暂停观测时已开窗口仍生效并计数，但样本暂停上报；恢复后继续；
- 面板开关关闭立即回 60 行并清计数，重开从 0 起算且旧窗口已清；面板开启会写回 `localStorage`；
- 诊断/降频/回填三项全关后包装卸载，只开本项（另两项关）也会重新装上；换 store 后新包装计数从 0；
- `__lagfixOff()` / 自禁用：设置回 false（自禁用仅内存、不落盘）、清窗口/计数、还原包装、样本 `switchPage=null`；
- `loadOlderRows30s` 按实际行数增量累加；失败页即使改变了行数也不累加；旧样本报告显示 `-`；
- 报告覆盖开+已装、未装上、`applied=0`、关闭、暂停、自禁用、旧样本与坏数字。

## 已知边界

- 自动化测试使用合成 DOM/store，不等同于 Windows/macOS 实机验收；首次安装后仍需实机确认观测与开关。
- 本版**不处理切换瞬间的 1 秒级帧**（多为宿主卸载/挂载/水合，切换后 2 秒内补页数为 0），也不声称切换已变快；切换期微批留给 v0.4.5。
- 只减少补页调用次数，不降低宿主单次补页的全量过滤成本；A/B 未过门槛时保持默认关闭，并如实标注。
- 若宿主未来改变 `loadOlder` 的参数含义、默认页大小或协议上限，本实验必须停用并在报告中提示，不猜参数。
