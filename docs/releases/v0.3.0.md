# v0.3.0

首个公开发布版本。观测 + 订阅通知节流 + 四项可逐项关闭的性能增强，全部只影响渲染时机，不改消息、会话数据与工具执行。

## 新增

- **状态条浮在输入框上方**：显示判定结论（极流畅/流畅/正常/轻微/卡/很卡）、帧 P95 与齿轮入口；只在主页面显示，设置页/弹窗/被遮挡时隐藏；同时挂多个 composer 时取最靠下的可见者。
- **不压输入区与排队面板**：位置改为输入框顶边上方；与排队面板相交时整体让到队列上沿，绝不覆盖「立即发送 / 编辑 / 删除」；上方没有余量时暂时隐藏。
- **悬停/点击统计浮层**：大号帧 P95、六档颜色图例、最近 18 个采集周期柱状图、峰值/最低/最新、提交速率与长任务。
- **居中分类设置**（左侧：状态条 / 观测 / 修复 / 维护）：角标显隐与简洁/详细、黄红阈值、观测开关、采集间隔 1/3/5/10/30s、节流开关与窗口、四项性能增强、日志路径与上限、重启 ZCode。
- **修复页每项「!」说明**：点开写明该项影响什么、不影响什么；关掉「订阅通知节流」后，依赖它的窗口/自适应/冷静期/后台降频四行变灰且不可操作，大会话保护保持独立。
- **自适应窗口**：帧 P95 ≥80ms / ≥150ms 时窗口自动升到 200 / 300ms，1s 缓存。
- **切会话冷静期**：切会话后 10s 内窗口至少 250ms，避免新会话首屏被高频通知打碎。
- **后台降频**：`document.hidden` 时最多 1s 合并一次，回前台立即补发。
- **大会话保护**：行数 ≥800 且未全载时拦截一次性全量补拉，分享入口/分享弹层放行；关闭时自动补拉一次。
- **日志预算**：观测与运行日志共享总预算（默认 50MB，可设 20/50/100/200MB），超了从最旧文件删起，当天活动文件保留；维护页显示实际路径、当前日志量与文件数（不足 1MB 按 KB）。
- **一键还原**：控制台 `__lagfixOff()`；角标隐藏后 `Ctrl+Alt+L`（Mac `Cmd+Alt+L`）或 `__lagfixSettings()` 仍能打开设置。
- **零安装探针**：`tools/lagfix-probe.py --overlay`，不改 app.asar、不用退出 ZCode，先看到卡顿数字再决定装不装。

## 安装 / 升级注意

- 安装会修改 ZCode 的 `app.asar`；首次注入成功后必须**完全退出 ZCode（含托盘）再重开**，只关窗口或重开会话不算。
- 需要 ZCode 桌面版 + Python 3.8+；不用装 Node，也不用装第三方 Python 包。
- ZCode 升级会覆盖注入，保持插件启用并在新会话触发 `SessionStart` 钩子即可自动修复；也可以执行 `/lagfix install`。
- 权限不足（如装在 `Program Files`）时注入会失败，失败原因写到 `~/.zcode/zcode-lagfix/hook-error.log`。
- 卸载先完全退出 ZCode，按 `/lagfix off` 的说明剥注入行并写 `.lagfix-optout`，再在设置 → 插件里卸载。

## 已知边界

- 面板「检查更新」仍置灰：当前通过重新执行安装口令升级，不提供“已是最新”这类假结论。
- 打开子智能体（Subagent）面板时的卡顿已记录，计划在 v0.3.x 先量清 DOM 规模/订阅通知/面板挂载哪一项为主，再决定是否加独立开关。
- 状态条依赖宿主 `.chat-composer-input-surface` 与投影 store 的内部形状；ZCode 大版本改版可能需要适配。
