# v0.3.3

侧栏开合、面板常开期与回前台保护版本。把「打开右侧面板卡一下」「面板开着时持续发涩」「从别的应用切回 ZCode 卡一下」拆成三段独立保护，并新增 `pane` / `refocus` 两组只读归因。四项开关默认开、可单独关闭；关闭后行为回到 v0.3.2。`/lagfix report` 新增「侧栏开合」与「回前台」两段。

仍然保持原有边界：不改消息与会话数据、不写 store、不读写 `db.sqlite`、不开 CDP、不联网上报。唯一的网络请求仍是用户手动点击「检查更新」时查询一次 GitHub Releases。

## 新增

- **P0 侧栏 / 回前台归因（默认开）**：`pane` 记录 `detected / open / panelPx / switches / switchP95 / switchMax / guardHits`；`refocus` 记录 `hiddenMs / sinceVisibleMs / p95 / max / flushes / guardHits`。只读宿主既有标记与几何，不写 store、不读消息内容。关闭 `paneDiagOn` 后两段均为 `null` 并释放侧栏 MutationObserver；P3 若仍开，只保留回前台所需的基线 `visibilitychange` 与 `focus/blur` 监听。
- **P1 侧栏开合 420ms 保护（默认开）**：宿主显式展开/收起时给 `documentElement` 加 `data-lagfix-pane-switch="1"`，420ms 内：
  - `[data-panel]` 的过渡时长压到 `0s`（瞬开/瞬收，不再每帧重排）；
  - 消息层 `mask-image` 临时关闭；
  - 角标 `positionBadge()` 直接返回，不再每帧读 composer 几何。
  拖拽改宽不触发；同一段开合 150ms 内去重。
- **P2 面板常开期保护（默认开）**：外框 `aria-hidden !== "true"` 期间保持 `data-lagfix-pane-open="1"`，期间消息层 mask 关闭、通知节流下限 300ms、角标定位最多每 1.8s 一次。面板收起或关闭开关立即移除属性。
- **P3 回前台保护（默认开）**：`visibilitychange` 或 `blur→focus` 回到前台后 700ms 内通知节流下限 400ms、前 300ms 跳过角标定位；后台积压的通知合并为一次 120ms 后的补发。关闭 `refocusGuardOn` 时恢复 v0.3.2 的同步补发。
- **面板「侧栏与回前台」组**：新增四行开关及「!」说明，分别写清影响/不影响；版本行更新为 v0.3.3。
- **`/lagfix report` 两段新输出**：
  - 侧栏：最近样本的 `detected/open/panelPx/switches/guardHits`，最近一次开合的帧 P95/max；按 open/closed 分组的 `frameP95/longTasks/dom` 中位数对比；
  - 回前台：`hiddenMs/sinceVisibleMs/p95/max/flushes/guardHits`，并按后台时长 `<1s / 1–10s / 10–60s / >60s` 分桶。
  缺标记、关闭、旧样本分别给提示，不静默当成 0。

## 调整

- **设置面板文案去黑话**：观测与性能页的「!」说明统一改成「会做什么 / 不会做什么」，有代价的单列「代价」一段；移除 `P95`、`DOM`、`loadOlder`、`mask-image`、`data-session-id`、`pane/refocus 字段` 等内部词。行名同步改为用户能直接理解的叫法：合并刷新、卡顿时自动放慢、切换会话时放慢、后台时减少刷新、滚动时去掉渐隐、多会话分别统计、侧栏与回前台统计、侧栏开合保护、面板常开保护。统计浮层、角标提示、性能页底部状态行也改为「每帧 / 刷新 / 卡顿 / 内存」的大白话解释。
- **角标定位增加三处早退/降频**：P1 保护窗口与 P3 前 300ms 直接返回，P2 常开期限流到 1.8s；避免面板动画/回前台首帧期间 `surfaceRO → positionBadge()` 反复强制布局。
- **`effectiveThrottleMs` 增加两个下限**：面板常开期 ≥300ms，回前台 700ms 内 ≥400ms；不改变用户手动设置的更高值。
- **回前台补发合并**：v0.3.2 在 `visibilitychange` 里同步遍历 `bgFlushers`，一次任务内可能连续提交多次；现在先合并到一个 120ms 定时器，只补发一次。`flushes` 统计实际被调用的 flusher 数。
- **清理路径统一**：关开关、observer 自禁用、`__lagfixOff()` 都会移除 `data-lagfix-pane-switch` / `data-lagfix-pane-open`、清掉 420ms/120ms 定时器、断开侧栏 MutationObserver，并把 `pane/refocus` 归因清零。`visibilitychange` 按 v0.3.2 基线保留（暂停/自禁用时才移除）；P3 的 `focus/blur` 随 `paneDiagOn`/`refocusGuardOn` 装卸，`__lagfixOff()` 会移除。
- **暂停语义**：暂停期间不启动新的 420ms 保护、不累计开合/回前台样本；payload 固定带 `pane: null, refocus: null`。
- **设置 key 不变**：仍是 `localStorage["lagfix.settings.v1"]`，新增 `paneDiagOn / paneSwitchGuardOn / paneHoldOn / refocusGuardOn` 四个键，旧设置缺键按默认 `true`。

## 安装 / 升级注意

- 从 v0.3.2 升级会替换 `app.asar` 注入；首次注入成功后必须**完全退出 ZCode（含托盘）再重开**，只关窗口或重开会话不算。
- 不需要新依赖；仍然是 ZCode 桌面版 + Python 3.8+。
- 如果觉得面板开合失去 200ms 滑动感，关 **P1 侧栏开合保护** 即可；如果觉得聊天文字刷新变慢，关 **P2 面板常开期保护** 即可。两者互不影响。

## 已知边界

- **三段各管一段**：P1 管开合 420ms，P2 管面板常开期，P3 管回前台 700ms；如果卡顿来自预览 HTML 自身持续绘制或宿主其它长任务，这三段仍可能不够，属于 v0.3.4 的 O4/预览侧方案。
- **依赖宿主标记**：`[data-workspace-side-frame="true"]`、`aria-hidden`、`[data-panel]`、`transition-[flex-grow]` 任一改动，侧栏检测会降级为 `detected=false` 或不再触发保护；报告会提示，不静默假装生效。
- **P1 会让开合动画消失**：保护窗口内面板瞬开/瞬收，不再有 200ms 滑动感；这是用视觉换主线程。
- **P2 有视觉与刷新代价**：面板常开期间消息层不做渐变遮罩，聊天文字最多晚 300ms 刷新；Agent 收流、工具执行、消息落盘不受影响。
- **P3 只延迟插件的补发**：回前台后最多 120ms 才补发挂起通知，状态可能比宿主晚一拍；宿主自己的首帧重绘不被拦截。
- **`switchP95` / `refocus.p95` 是插件 rAF 帧间隔口径**，不是宿主 Long Task；样本窗口分别只有开合后 800ms / 回前台后 800ms，次数少时波动大。
- **`panelPx` 只在检测到侧栏外框时采样**，移动端 overlay 不写该标记，按 `detected=false` 处理。
- **日志量增加**：每个样本新增 `pane`/`refocus` 约 0.2–0.3KB；`paneSwitchRing`/`refocusRing` 只存在于内存，最多 240 帧，不落盘。
- **不保证所有机器都变快**：当前证据来自一台 Windows 机器、一个超长会话和两张侧栏截图；没有实机 A/B 前，不写“已修复卡顿”。
