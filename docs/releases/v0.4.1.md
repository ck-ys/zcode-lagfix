# v0.4.1

发布时间：2026-11-12
主题：角标「有新版本」红点移到齿轮右上角

## 背景

v0.3.7 起，角标里的更新红点是一个行内小圆点，排在指标文字与设置齿轮之间。v0.3.10 修复它「实际不可见」之后，实机看起来仍像一个多余的状态点，而不是「设置入口有未读提醒」。

用户反馈：应该像 QQ/微信的未读角标一样，贴在设置齿轮的右上角。

## 变更

- 红点 DOM 从角标容器移到齿轮按钮（`lagfix-gear`）内部，成为其子元素；id 不变（`lagfix-overlay-badge-update-dot`）。
- 红点样式改为绝对定位的角标：
  - `top:-2px; right:-2px;`，6px 圆点；
  - `box-shadow: 0 0 0 1.5px var(--color-popover, #161b22)` 与角标背景融合；
  - `pointer-events:none`，点击红点等同点击齿轮，仍打开设置。
- 红点不再自带 `title`，改为 `aria-hidden="true"`；齿轮 `title` 在有新版本时变为「打开设置（有新版本）」，隐藏后恢复「打开设置」。
- 角标容器保持 `overflow:hidden`；红点只伸进角标自身的上/右内边距，不越过裁切边界。
- 维护页「检查更新」行的行内红点保持不变。

## 明确不做

- 不改检查更新的网络请求、24 小时自动检查、缓存 key 或红点判定条件。
- 不改角标尺寸、指标文字、齿轮图标与点击行为。
- 不新增设置项、日志字段或 DOM 属性。
- 不改注入链、消息/会话数据或其它缓解项。

## 安装注意

- 本版仍会修改 `app.asar`。安装/更新后请**完全退出并重新打开 ZCode**（仅关闭窗口不算）。
- 升级不会改变任何开关选择；本版只影响角标红点位置与齿轮提示。

- `node tests/observe_smoke.mjs`：**537 项全部 PASS**。新增断言：红点是齿轮子元素、`aria-hidden` 且无自带 title、样式为右上角绝对定位与 `pointer-events:none`、齿轮 `title` 随显示状态切换、`__lagfixOff` 后提示恢复。
- `python tests/report_session_diag.py`：92 项 PASS。
- `line_regex`、`peer_gate`、`smoke_asar`、`install_remove`、`update_check`（25 项）、`log_budget`（33 项）：PASS。

实机验收：

1. 完全退出并重开 ZCode；
2. 维护页点「检查更新」，若有更高版本，红点应贴在设置齿轮的右上角；
3. 点红点或齿轮都能打开设置；悬停齿轮提示包含「有新版本」；
4. 没有新版本时红点消失，齿轮提示恢复为「打开设置」。

## 已知边界

- 红点是纯视觉提醒，不自动下载或安装；升级仍走安装口令。
- 角标背景色跟随宿主主题变量 `--color-popover`；宿主主题未提供该变量时使用默认深色描边。
- 自动化测试不等同于 Windows/macOS 实机验收。
