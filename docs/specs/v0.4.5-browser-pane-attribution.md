# v0.4.5 行为规格：浏览器面板与回前台归因（A）

日期：2026-11-15
状态：已实现（v0.4.5）
关联拍板页：`docs/decisions/v0.4.5-browser-pane-attribution.html`
前置版本：v0.4.4（`switchBackfillPageOn`、`loadOlderRows30s`）

## 0. 一句话目标

稳定打开 ZCode 内置浏览器时，宿主 UI 帧是平滑的（实机 P50/P95 中位 6ms），但宿主主线程仍有 130–337ms 的 LoAF 长帧；宿主 LoAF 来自 renderer 自己的 PerformanceObserver，看不到 guest 内部，因此不能直接说成「guest 页面内部长帧」。200–267ms 的宿主尖峰集中在回前台/页面加载，不是浏览器常开态。当前样本只有 `hidden`、`pane`、`refocus`，无法区分「选中的浏览器 guest」「窗口无焦点」「回前台」。本版只做**只读归因**：样本新增 `focus`、`webview`，报告把宿主帧与宿主 LoAF 并列，不改任何行为、不新增开关、不声称已优化 guest。

## 1. 范围

本版做：

- 正常采集样本新增 `focus`（`document.hasFocus()`）与 `webview`（当前选中的内置浏览器 tab 里是否有 guest）。
- 暂停、自禁用、异常兜底样本带 `focus:null, webview:null`，保持 schema 稳定。
- 报告新增「浏览器面板归因」段，按稳定浏览器、回前台 3 秒、无焦点、没有选中的 guest、旧样本分组。
- 稳定浏览器排除**同窗口**切换后 30 秒内的候选样本（有切换记录时），并明示帧 P50/P95 为最近 30 秒窗口、宿主 LoAF 为本采集周期值，不能把窗口前的尖峰说成已分离。
- `paneDiagOn` 按每条样本自己的设置判断：最新样本关闭归因时不丢弃更早的有效样本。
- `print_pane_diag` 的 open/closed 分组补 `frameP50` 中位，与现有 P95 并列；旧样本显示 `-`；`P50` 只覆盖部分样本时样本数仍按全部行计。
- 报告尾部版本摘要更新为 v0.4.5。
- 测试、版本文档、AGENTS 范围、README/发布说明。

本版不做：

- 不做回前台保护 v2、不做切换瞬间微批、不做浏览器打开期更强节流。
- 不改 `switchBackfillPageOn`、`loadOlderPaceOn`、`turnContentVisOn`、`panelQuietOn` 等任何默认值或行为。
- 不进入 `<webview>` guest、不执行 guest JS、不读 URL/标题/页面内容；不打开 CDP。
- 不读 `~/.zcode/cli/db.sqlite`，不读会话正文/提示词/回复/工具参数，不联网上报。
- 不折叠/隐藏任何内容，不改消息、会话、工具结果。
- 不修 zusage，不升级/禁用它。

## 2. 宿主契约核对

- 内置浏览器由 `BrowserViewportSurface.tsx:143` 渲染 `<webview>`；`UnifiedBrowserView.tsx:41–45` 说明 CDP-on-guest、页面像素由 guest 在 renderer 内合成。
- 宿主有两条浏览器路径：
  - `browser-use` tab：`BrowserUseSidePaneContent.tsx:61–75` 用 `TabsContent forceMount`，未选中时 `aria-hidden="true"`、`hidden`，但 guest 不卸载；选中态带 `data-browser-use-tab-id` 且 `aria-hidden="false"`。
  - 人类浏览器 tab：`AnimatedSidePanePanel.tsx:1231–1515` 用通用 `TabsContent forceMount`，没有 `data-browser-use-tab-id`；`HumanBrowserView` 最终也走 `BrowserViewportSurface`，guest 带 `data-testid="browser-webview"` 与 `partition="persist:zcode-embedded-browser"`。选中态由 Radix 的 `data-state="active"` 表示，未选中态带 `data-[state=inactive]:hidden`。
- 侧栏外框仍是 `[data-workspace-side-frame="true"]`；`pane.open` 仍由现有 `paneDiagOn` 探针提供。
- `document.hasFocus()` 是标准 DOM API；它只表示文档是否有前台焦点，不表示窗口是否被其他应用遮挡。Electron 上游曾记录 guest 抢焦点时顶层文档 `hasFocus()` 可能为 `false`（electron/electron#26497），本版未在 ZCode 44.7.0 实机复核，因此报告单独提示「guest 存在但文档无焦点」，不把它算进稳定组。
- 选中的浏览器 guest 用两段查询：browser-use 选中 tab 内的 `webview`；通用选中 tab 内的 `webview[data-testid="browser-webview"]`。旧宿主没有 tab 标记时只认浏览器专属 `data-testid`/`partition` 且有布局盒的 guest，**不再裸查任意 `<webview>`**，避免把插件 UI、奖励页、预览等 guest 误算成浏览器。
- 宿主未来若改标签或把 webview 放进 shadow root，`webview` 会返回 0 或 `null`；报告必须明示「没有检测到选中的 guest」，不能推断「没有卡顿」，也不能推断「宿主结构变化」。

## 3. 样本字段

### 3.1 正常采集

新增两个字段：

```
focus: boolean | null
webview: 0 | 1 | null
```

- `focus`：
  - `typeof document.hasFocus === "function"` 时调用，返回 `!!document.hasFocus()`；
  - 抛异常或 API 不存在时返回 `null`；
  - 不缓存，不新增监听器。
- `webview`：
  - 先查 `[data-browser-use-tab-id]:not([aria-hidden="true"]) webview`：命中返回 `1`（browser-use 选中 tab 内的 guest）；
  - 再查 `[data-side-pane-content-slot] [data-slot="tabs-content"][data-state="active"] webview[data-testid="browser-webview"]`：命中返回 `1`（人类浏览器选中 tab）；
  - 文档里有 `[data-browser-use-tab-id]` 但都不是选中态时返回 `0`，不再退回裸 `webview`；未选中的 tab 仍挂载或处于截图合成态也不算；
  - 没有 `[data-browser-use-tab-id]` 时（旧宿主/只有人类 tab），只查浏览器专属 `webview[data-testid="browser-webview"]` 或 `webview[partition="persist:zcode-embedded-browser"]`，任一有布局盒返回 `1`，否则 `0`；**不把插件 UI、奖励页、预览等普通 `<webview>` 算成浏览器**；
  - 查询抛异常返回 `null`；
  - 只判断选中的 guest 是否存在，不读 `src`、标题、URL、页面内容、历史，不统计数量。
- 每采集周期只读一次 `focus` 和浏览器选择器；不遍历全 DOM，不新增定时器。
- `focus`/`webview` 与 `paneOpen` 都是文档级信号：隐藏的会话 pane 若仍挂载选中的浏览器、当前可见 pane 是预览/终端，`webview` 可能仍为 `1`；本版不按会话 pane 拆分，报告只做汇总解读。
- 不根据 `webview=1` 自动认定页面内部有长帧；报告必须同时看 `paneOpen`、`focus`、切换记录与宿主 LoAF。

### 3.2 暂停 / 自禁用 / 异常兜底

- `state.dead` 分支：`focus:null, webview:null`，不读 DOM。
- `!settings.observe` 分支：`focus:null, webview:null`，不读 DOM。
- 正常采集的 catch 兜底：`focus:null, webview:null`。
- 旧样本没有这两个字段；消费端按 `undefined` 处理，不补 0。
- `__lagfixOff()` 不是暂停/自禁用：仍按正常采集写入 `focus`/`webview`，与 v0.4.4 的观测保留策略一致；本版不新增清理逻辑。

### 3.3 字段语义

| 字段 | 为 true/1 | 为 false/0 | 为 null |
| --- | --- | --- | --- |
| `focus` | 文档有前台焦点 | 文档无前台焦点（窗口失焦、DevTools 抢焦点等） | API 不可用/查询异常/暂停/自禁用 |
| `webview` | 当前选中的内置浏览器 tab（browser-use 或人类浏览器）里有 guest | 没有选中的浏览器 tab/guest（未选中 tab 仍挂载也不算；插件 UI/奖励页/预览也不算） | 查询异常/暂停/自禁用 |

`focus=false` 不等于 `hidden=true`；`webview=0` 不等于「没有浏览器面板」——可能只是当前侧栏是预览/终端，或浏览器 tab 未选中；也不能据此推断 guest 已卸载或宿主结构变化。关闭侧栏但浏览器 tab 仍处于选中态时，`webview` 可能仍为 `1`，报告会用「侧栏标记为关闭」单独提示。

## 4. 报告

新增 `print_browser_diag(rows)`，在 `print_pane_diag(rows)` 之后调用。只做分组统计，不下「已优化」结论。

### 4.1 分组

只使用 `webview` 字段存在且非 `null` 的样本；`hidden` 或 `miss` 样本不进入任何性能分组。

| 分组 | 条件 | 输出 |
| --- | --- | --- |
| 稳定浏览器 | `webview==1` 且 `paneOpen===true` 且 `focus===true` 且 `!hidden` 且 `!miss`，`refocus.sinceVisibleMs` 是数字且 `>3000`；该样本自己的 `settings.paneDiagOn` 不是 `false`；有切换记录时，样本 `t` 不在**同窗口**任意切换后 30 秒内 | 样本数；`frameP50`/`frameP95` 中位；长任务中位/最多；宿主 LoAF 最长 |
| 回前台 3 秒 | `focus===true` 且 `refocus.sinceVisibleMs` 是数字且 `<=3000`；不限浏览器；该样本自己的 `paneDiagOn` 不是 `false` | 样本数；`frameP50`/`frameP95` 中位；长任务中位/最多（不输出 LoAF） |
| 无焦点 | `focus===false` 且 `!hidden` 且 `!miss` | 样本数；`frameP50`/`frameP95` 中位；明示不计入浏览器结论 |
| 没有选中的 guest | `webview===0` 且 `paneOpen===true` 且该样本 `paneDiagOn` 不是 `false` | 样本数；中性说明「预览/终端等普通面板也会如此」，不推断宿主结构变化 |
| 旧样本 | 没有任何样本带 `webview` 字段 | 提示「本版本未记录浏览器标记（v0.4.5 前的旧样本）」 |
| 全为 null | 有字段但所有值都是 `null` | 提示「浏览器标记不可用（暂停/自禁用/查询异常）」 |

- 回前台组可以包含非浏览器样本，输出里明确标「不限浏览器」。
- 稳定浏览器组必须同时满足 `paneOpen`、`focus`、`webview`、该行 `paneDiagOn`，且 `refocus.sinceVisibleMs` 是数字并 `>3000`；`paneDiagOn=false`、`refocus=null` 或 `sinceVisibleMs=null` 时不把该行算进稳定组。`sinceVisibleMs=null` 表示启用归因时文档隐藏、探针尚未启用或旧样本，回前台窗口不可判断，不能当成“不在回前台窗口”。**不能用最新样本的 `paneDiagOn` 否定更早的有效样本**。
- observer 在归因启用/恢复观测且文档可见时，把启用时刻写为可见起点；因此用户从不切出再切回的会话，3 秒后也能进入稳定组，不会永久停在 `null`。启用后的前 3 秒仍按回前台窗口排除，避免把启动/恢复观测的尖峰算成常开态。
- 若最新样本是暂停/自禁用但更早有有效样本，标题明示「以下为历史有效样本汇总，不代表当前瞬间」，不得把旧样本冒充当前。
- 若最新样本自己的 `paneDiagOn=false`，只说明「最新样本的归因已关闭」；历史有效样本仍保留，并标注「来自更早的有效样本」。
- 若 `webview=1` 但 `paneOpen===false`，提示「侧栏标记为关闭」；`paneOpen===null` 单独提示「侧栏是否打开未知」，不并入关闭。
- 统计范围行显示样本数、窗口 id；多窗口时明示「跨窗口汇总，中位数可能混合窗口」。
- 回前台组为空时明确打印「本文件没有样本落在回前台 3 秒窗口内」；存在 `sinceVisibleMs=null` 的候选样本时打印「回前台窗口不可判断」，不得说成「没有样本」；最新样本关闭侧栏归因时打印「回前台窗口不可判断」。
- 检测到 `webview=1` 且 `paneOpen=true` 但 `focus=false` 的样本，在无焦点组后额外提示「可能 guest 抢焦点或窗口失焦，不计入稳定组」。
- 只在隐藏/丢锚点样本中检测到 `webview=1` 时，明示「只在隐藏/丢锚点样本中检测到」，不说成「本文件没有 guest」。
- 稳定组有数据时：有切换记录则显示排除了多少条**同窗口**切换后 30 秒内候选；没有切换记录则明示「无法排除切换后尖峰」；并提示帧 P50/P95 为最近 30 秒窗口、宿主 LoAF 为本采集周期值，窗口内仍可能含更早的回前台/加载尖峰。
- 稳定组为空且候选样本全部被切换窗口排除时，必须说明「候选样本都在同窗口切换后 30 秒内」，不能落到「需要侧栏打开、有焦点」的通用提示。多窗口汇总时，切换时间按 `win` 分桶，`win-a` 的切换不得排除 `win-b` 的干净样本。

### 4.2 统计口径

- 帧值取每条样本的 `frameP50`/`frameP95`，先各自求中位数；不把 P50 与 P95 混算。
- 长任务取每条样本的 `longTasks`，输出中位与最多；`maxLongTask` 可作为补充但不强制。
- LoAF 最长取每条样本 `laf.max` 的最大值，标签必须是「宿主 LoAF 最长帧」；`laf` 不支持或缺失时不输出该指标。
- 样本数按实际进入分组的行数计算，不用各指标数组长度的最大值代替。
- 样本数小于 3 时提示「样本少于 3 条，结论仅供参考」，不阻止输出。
- 旧样本缺 `frameP50` 时显示 `-`，不回退成 P95。
- 回前台 3 秒组不输出宿主 LoAF；LoAF 只属于稳定浏览器组，避免把回前台尖峰当成浏览器常开证据。

### 4.3 结论句

只在稳定浏览器组有数据时打印，且必须同时有宿主 P95 与宿主 LoAF：

- `frameP95` 中位 `<=16ms` 且 `laf.max >=100ms`：
  `宿主 UI 帧平滑，但宿主主线程仍有 ≥100ms 长帧；来源未分（guest 合成/宿主定时器/样式），不能据此认定是 guest 页面内部。`
- `frameP95` 中位 `>50ms` 且 `laf.max >=100ms`：
  `宿主也被拖慢，需继续分回前台/切换/浏览器面板；本段不归因到 guest。`
- 其他情况不打印结论句，只打印数据。

不得把 `webview=1` 直接写成「浏览器页面卡」；不得把宿主 LoAF 写成 guest 内部长帧。稳定组只按采样时刻排除回前台 3 秒，且帧 P95 是 30 秒窗口、LoAF 是采集周期值；默认 5 秒采集下，回前台后第 3–5 秒的样本仍可能包含回前台尖峰，报告必须明示这一限制。

### 4.4 现有 pane 段

- `print_pane_diag` 的 open/closed 分组新增 `P50 中位`，附在现有行末，保留原有 P95/长任务/DOM 文案作为前缀，避免破坏旧消费端的 grep。
- 旧样本没有 `frameP50` 时输出 `P50 中位 -`。
- `P50` 只覆盖部分样本时，样本数 `n` 仍按该分组全部有效行计算（包含 `frameP50/frameP95/longTasks/dom` 任一存在的行），并在行内显示 `P50 中位`，不能把只有 P50 的行判成「没有可用样本」。
- 不改回前台 `hiddenMs` 分桶、保护命中、开合统计。

### 4.5 报告尾部

版本摘要改为 v0.4.5，说明本版只新增浏览器/焦点标记与报告分组，默认开关与 v0.4.4 一致。

## 5. 安全与清理

- 硬红线不变：不读写 `~/.zcode/cli/db.sqlite`，不读会话正文/提示词/回复/工具参数，不开 CDP，不联网上报；不删除用户会话或日志。
- 本版不新增设置键、DOM 属性、全局监听器、定时器或包装器；`focus`/`webview` 只在采集时读取。
- `__lagfixOff()`、暂停、自禁用、异常兜底不需要新增清理逻辑；现有清理路径保持不变。
- 回退：删除 `focus`/`webview` 采集与 `print_browser_diag` 即可回到 v0.4.4；不影响任何缓解项。
- 隐私：`webview` 只是 0/1，不包含 URL、标题、页面内容或会话信息。

## 6. 测试要求

`tests/observe_smoke.mjs` 至少覆盖：

1. 正常样本 `focus=true` 与 `focus=false`；字段是 boolean。
2. browser-use 选中 tab 内存在 guest 为 1；未选中的 browser-use tab 即使 guest 仍挂载也为 0；人类浏览器选中 tab 为 1；存在未选中的 browser-use tab 时人类浏览器仍能识别；没有 guest 为 0；查询抛异常为 `null`。
3. 旧宿主没有 tab 标记时，浏览器专属 guest（`data-testid="browser-webview"` 或浏览器 partition）有布局盒为 1、无布局盒为 0；可见的插件 UI/预览/奖励页 `<webview>` 必须为 0，且代码不得裸查 `document.querySelector("webview")`。
4. `document.hasFocus` 抛异常/不存在时为 `null`，不向宿主冒泡。
5. 暂停样本 `focus=null, webview=null`；恢复后正常读取；归因启用且文档可见时 `sinceVisibleMs` 是数值（不因从未回前台而永久为 `null`）。
6. 自禁用样本 `focus=null, webview=null`；`__lagfixOff()` 后仍按正常采集，与 v0.4.4 一致。
7. 异常兜底路径字段为 `null`；`querySelector` 与浏览器 guest 列表查询各自抛异常都不崩。
8. 旧样本/缺字段不报错；样本体积增加不超过 50 字节。
9. 现有全部断言继续通过。

`tests/report_session_diag.py` 至少覆盖：

1. 稳定浏览器组：`webview=1 + paneOpen=true + focus=true`，P50/P95、长任务、宿主 LoAF 输出正确。
2. 回前台组：`sinceVisibleMs=115` 与 `2375` 都单独计数，不混入稳定浏览器；`3001` 回到稳定组；`sinceVisibleMs=null` 时窗口不可判断、不进入稳定组；回前台组不输出宿主 LoAF。
3. 无焦点组：`focus=false` 不计入稳定浏览器，输出明示；`webview=1 + paneOpen=true + focus=false` 额外提示可能 guest 抢焦点。
4. `webview=0` 且 `paneOpen=true` 时说成「可见样本中没有选中的 guest」，不吓成宿主结构变化；只在 hidden/miss 样本检测到 guest 时单独说明。
5. 旧样本无 `webview` 字段提示；全 null 提示。
6. 只有 `webview=1` 但 `paneOpen=false` 时不进入稳定组，单独提示侧栏关闭；`paneOpen=null` 单独提示未知。
7. `paneDiagOn=false` 且 `refocus=null` 时不进入稳定组，并说明回前台窗口不可判断；历史样本有效、最新样本 `paneDiagOn=false` 时历史稳定样本仍保留，且不输出矛盾的侧栏计数。
8. 宿主 P95>50ms 的结论分支、样本少于 3 条提示、LoAF 缺失时不输出、跨窗口汇总标注；同窗口切换后 30 秒内候选排除、切换排除按 `win` 隔离、全部候选被切换排除时的专用提示、无切换记录时的限制提示、帧窗口/回前台窗口不完全重合的提示。
9. `print_pane_diag` 的 P50 正常/缺失显示；P50 只覆盖部分样本时样本数仍按全部行计。
10. 版本摘要更新为 v0.4.5。

## 7. 验收

- 自动化测试全部通过；无新增网络请求、无新增 CDP、无写真实安装目录。
- 实机：同一会话打开 browser-use 浏览器 10 分钟，`/lagfix report` 出现稳定浏览器样本；再用人类浏览器 tab 重复一次，`webview=1` 仍成立；12:15/12:16 类回前台样本（含 2375ms）进入回前台组；切到预览/终端或未选中浏览器 tab 时 `webview=0`，不混入稳定浏览器。
- 实机抽验 `document.hasFocus()`：分别在聊天输入框有焦点、点击/滚动浏览器页面、窗口失焦三种状态下看样本。若点击 guest 时 `focus=false`，说明稳定组只覆盖宿主聊天区有焦点的时段；报告会单独提示「guest 存在但文档无焦点」，不得把稳定组当成浏览器使用全貌，后续版本再补 guest 焦点标记。
- 实机打开插件 UI/奖励页/预览，确认 `webview=0`；不能因为文档里有 `<webview>` 就算浏览器。
- 多窗口场景只做汇总并标注窗口 id；本版不承诺窗口级中位数。
- 开销：每样本只多一次 `hasFocus()`、最多两次选中 tab 查询与一次浏览器专属列表查询；无新增 ≥50ms 长任务。
- 本版不以「变快」为验收；只验收归因正确、旧样本兼容、关闭/暂停清理路径不变，以及不把宿主 LoAF、回前台/切换尖峰误标成 guest 内部成本。
