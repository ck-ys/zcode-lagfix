# v0.4.1 行为规格：角标更新红点移到齿轮右上角

状态：已拍板（2026-11-12，用户确认「偏右上角好一点，按推荐修复」）。
单点视觉修复，不改检查更新逻辑、缓存结构与维护页红点。

## 1. 目标

角标里的「有新版本」红点从「指标文字与齿轮之间的行内点」改为**齿轮按钮右上角的角标**，
接近 QQ/微信未读提醒的语义：

- 不占横向文字空间；
- 一眼看出提醒属于「设置/维护」入口；
- 不遮挡齿轮图标与点击区。

## 2. DOM

- 红点元素 id 不变：`lagfix-overlay-badge-update-dot`。
- 红点从角标容器移到齿轮按钮（`lagfix-gear`）内部，作为其子元素。
- 红点设置 `aria-hidden="true"`，不再带自己的 `title`（避免与齿轮提示重复）。
- 齿轮 `title` 随状态切换：
  - 无新版本：`打开设置`；
  - 有新版本：`打开设置（有新版本）`。

## 3. CSS

- `.lg-gear` 增加 `position:relative`。
- `.lg-update-dot`：
  - `position:absolute; top:-2px; right:-2px;`
  - `width:6px; height:6px; border-radius:50%; background:#f85149;`
  - `box-shadow:0 0 0 1.5px var(--color-popover,#161b22);`
  - `pointer-events:none; display:none;`
- 角标容器保持 `overflow:hidden`；红点只伸进角标自身的上/右内边距（上 3px、右 5px），
  不越过裁切边界。
- 红点不接收指针事件：点击红点等同于点击齿轮，仍打开设置。

## 4. 状态与还原

- 显示条件不变：`newer === true`、缓存 `current === VERSION`、`latest` 非空且 `latest !== VERSION`。
- `syncUpdateDot()` 仍负责显示/隐藏：显示写 `inline-block`，隐藏写 `none`；同时更新齿轮 `title`。
- `__lagfixOff()`、跨窗口缓存、版本不匹配等路径行为不变。
- 维护页「检查更新」行红点（`lg-update-dot-inline`）保持行内样式，不移动。

## 5. 明确不做

- 不改检查更新的网络请求、24 小时自动检查、缓存 key 或红点判定条件。
- 不改角标尺寸、指标文字、齿轮图标与点击行为。
- 不新增设置项、日志字段或 DOM 属性。
- 不改注入链、消息/会话数据或其它缓解项。

## 6. 验收

`tests/observe_smoke.mjs` 至少覆盖：

1. 红点是齿轮按钮的子元素（`parentNode === gear`）；
2. 红点带 `aria-hidden="true"`，自身没有 `title`；
3. 样式含绝对定位、右上角偏移、`pointer-events:none`，齿轮含 `position:relative`；
4. 默认隐藏、有新版本显示、跨窗口显示、`current > latest` 不显示、`__lagfixOff` 清理五条路径的
   `display` 断言保持；
5. 有新版本时齿轮 `title` 含「有新版本」，隐藏后恢复「打开设置」；
6. 维护页行内红点位置与显示逻辑不变。
