# v0.4.0 行为规格：O8b 自适应补页（默认关闭的实验）

状态：已拍板（2026-11-12，用户确认 v0.4.0 推荐 A「T1 + U2 + O8b」后开始实现）。
替代 v0.3.6 的 O8「固定 200 行」实验；O3 的开关与语义不变。

## 1. 目标

保留「减少后端补页次数」的收益，同时避免连续 200 行前插放大滚动锚点跳动：

- 孤立补页：120 行/次；
- 连续补页（<600ms）：降回宿主默认 60 行/次；
- 只对已加载窗口 >3000 行生效；
- **不跳过任何调用**。

## 2. 常量

| 常量 | 值 |
| --- | --- |
| `LOAD_OLDER_PAGE_LIMIT` | `120` |
| `LOAD_OLDER_PAGE_MIN_ROWS` | `3000` |
| `LOAD_OLDER_PAGE_BURST_MS` | `600` |

## 3. 包装规则

只包装当前主 store **实例**的 `loadOlder`；安装条件保持
`scrollDiagOn || loadOlderPaceOn || loadOlderPageLimitOn`（且 `!state.dead`）。

无参调用：

1. 读 `this.state.snapshot.rows.window.length`（只读长度）。
2. 记录 `now = performance.now()`，并更新本次包装的 `lastAt = now`。
3. 若行数可读且 `rows > 3000`：
   - 若 `now - lastAt(上一次)` >= 600ms：调用 `orig.call(this, 120)`，计 `applied`；
   - 否则：调用 `orig.call(this)`（宿主默认 60），计 `downgraded`。
4. 若行数不可读或 `rows <= 3000`：调用 `orig.call(this)`，计 `small`。
5. 显式参数：原样 `orig.apply(this, arguments)`，计 `passthrough`；不更新 `lastAt`。

注意：`lastAt` 必须在判断前保存旧值，再用旧值计算间隔，最后写入本次时间；
不能先写入再比较，否则永远不进入 burst。

必须保留：

- `this` 接收者；
- 原 Promise 引用、返回值与异常；
- `loadingOlder` / `canLoadOlder` 状态；
- 调用顺序与结果内容。

不得：

- 跳过调用或返回伪造的已结算 Promise；
- 合并、缓存、删除、重排数据；
- 修改 store、会话、消息或工具结果；
- 在共享原型上留下包装。

## 4. 与 O3 的关系

- O3 `loadOlderPaceOn` 仍在 O8b 之前判断；O3 跳过时原方法不被调用，O8b 不计数。
- 两者同关才卸载包装；只开 O8b 也必须安装并生效。
- O3 的 `pace.allowed/skipped` 语义不变。

## 5. 计数与样本

每个包装实例维护：

```js
{ applied: 0, downgraded: 0, small: 0, passthrough: 0, lastAt: -1e9 }
```

样本（开关开启且未自禁用）：

```json
"page": {
  "limit": 120,
  "minRows": 3000,
  "burstMs": 600,
  "installed": true,
  "applied": 2,
  "downgraded": 5,
  "small": 1,
  "passthrough": 0
}
```

- 开关关闭 / 自禁用：`page=null`。
- `installed=false`：包装未装上，计数不可用。
- 暂停观测：替换仍生效，计数继续累计，样本照实上报（与 v0.3.6 一致）。
- 从关到开、换 store、自禁用、`__lagfixOff()`：计数与 `lastAt` 清零；
  暂停观测不清零。

## 6. 面板

「补页批量 · 实验」文案改为：

- 名称不变；
- 说明：一次最多 120 行；连续快速上翻时自动回到每页 60 行；
- 明确：不跳过、不删除、不改顺序；这是实验，默认关闭。

## 7. 报告

补页段显示：

- 页大小 120；
- `applied`（120 行生效）；
- `downgraded`（连续补页降回 60）；
- `small`（窗口未超过 3000 行，按 60）；
- `passthrough`（显式参数放行）；
- `installed=false` 时明确「包装尚未装上，计数不可用」；
- 旧样本没有新字段时只显示已有字段，不把缺失当 0 解释。

## 8. 还原

- 关开关：下一次无参调用立即回到宿主默认 60；
- `__lagfixOff()`：开关置 false、包装卸载/还原、计数清零；
- observer 自禁用：同 `__lagfixOff()`；
- 宿主已替换 `loadOlder` 时不得覆盖宿主实现；旧 wrapper 引用由代际门控失效。

## 9. A/B 与去留

同一会话、同一段历史、同一路径，O4 固定关，做「O8 关 → O8b 开 → 关」至少 3 轮：

- 过线：补页调用次数下降 ≥30%；补页总耗时或滚动 P95/长任务不退化 >10%；
  `driftP95 <= 48px`；DOM 峰值增加 ≤20%。
- 未过线：保持默认关闭；若调用次数也没有明显下降，退役 O8，不再继续加页大小。

## 10. 验收

`tests/observe_smoke.mjs` 至少覆盖：

1. 默认关闭，三开关全关时包装卸载；
2. 只开 O8b 也安装；
3. 大窗口孤立调用 → 120，`applied=1`；
4. 600ms 内第二次调用 → 默认 60，`downgraded=1`；
5. 小窗口 → 默认 60，`small=1`；
6. 行数不可读 → 默认 60，不抛错；
7. 显式参数原样放行，`passthrough`；
8. `this`、原 Promise、同步异常语义不变；
9. 暂停观测仍替换并累计；
10. 关开关、重开、换包装、`__lagfixOff()` 的计数/时间戳清零与还原；
11. O3 跳过时 O8b 不计数。
