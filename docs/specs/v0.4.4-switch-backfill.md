# v0.4.4 行为规格：切换回填大页实验（B）

日期：2026-11-14
状态：已实现（v0.4.4）
关联拍板页：`docs/decisions/v0.4.4-switch-backfill.html`
前置版本：v0.4.3（`switchDiagOn` / `loadOlderN30s` / `loadOlderMs30s`）

## 0. 一句话目标

切回长会话后的 30 秒里，宿主会从 120 行开始以 60 行/页回填到 3000 行左右；实机 26 秒内出现 44 次 `loadOlder`、累计 4903ms、单次最高 575ms。本版只做一个默认关闭的实验：**在这 30 秒窗口内，把无参补页的每页 60 行提到 120 行**，用更少的调用和更少的中间提交完成同一段回填。不跳过、不合并、不缓存、不删数据、不隐藏内容。

## 1. 宿主契约核对

- `ConversationProjectionStore.loadOlder(limit = PROTOCOL_V4_LIMITS.snapshotTailWindowRows)`，`snapshotTailWindowRows = 60`，`rowsRangeMaxLimit = 200`。
- 调用点 `handleLoadOlder = useCallback(() => lease?.store.loadOlder(), [lease])`，宿主为 fire-and-forget；`loadOlder` 内部单飞（`loadingOlder` 防重入）。
- 已核对：v3.17.1 / v3.17.2 源码，v3.18.1 / v3.18.2 安装版 asar。
- 120 在协议允许区间内。若宿主未来改变参数含义、默认页大小或上限，本实验停用并在报告中提示，不猜参数。

## 2. 范围

本版做：

- 新增 `switchBackfillPageOn`（默认 `false`）与 v0.4.4 切换回填大页行为。
- 切换记录新增 `loadOlderRows30s`（只读），用于「每 1000 行」归一化 A/B。
- 样本新增 `switchPage` 健康计数、报告新增对应段落。
- 测试、版本文档、AGENTS 范围、README/发布说明。

本版不做：

- 切换瞬间拆批（A）：不改通知节流窗口、不跳角标、不改 mask；留给 v0.4.5 独立实验。
- 不改 O3 `loadOlderPaceOn` 的默认值、门槛或跳过行为。
- 不跳过补页、不合并分页、不缓存、不预取、不改消息/会话/工具结果、不折叠或隐藏内容。
- 不处理 1 秒切换帧本身；不声称本版让切换变快。
- 不升级/禁用 zusage，不做新网络请求，不读 `db.sqlite`，不开 CDP。

## 3. 开关与默认值

- 设置键：`switchBackfillPageOn`，布尔，默认 `false`。
- 归入面板「性能 → 实验」，排在「大会话翻页降频 · 实验」之后。
- 面板文案（用户语言，不出现 `loadOlder`/`rows.window`/`store` 等内部词）：
  - 标题：「切换后大页补页 · 实验」
  - 摘要：「切换会话后的 30 秒内，每次多取一点历史（60 → 120 行），减少来回次数。30 秒后自动恢复。」
  - 会做什么：「切换会话后的 30 秒内，只要还在连续补历史，每次从 60 行提到 120 行；超过 3000 行或 30 秒后自动回到 60 行。」
  - 不会做什么：「不跳过任何一页，不合并、不删除、不改消息顺序，也不改会话数据；只改变这一页取多少行。」
  - 代价：「单次可能稍慢；如果看到历史空白或位置跳动，关掉即可恢复。」
- 关闭时与 v0.4.3 完全同路径：不装包装（除非观测/降频需要）、不写计数、样本 `switchPage=null`。

## 4. 触发与调用规则

### 4.1 真实切换窗口

- 在 `recordSwitch(fromSid, toSid)` 入口、`switchWatchActive()` 门控之前写 `switchBackfillAt = performance.now()`，仅当：
  - `fromSid` 与 `toSid` 都是真实会话：非空、非 `"draft"`（复用 `isPlaceholderSid`）；
  - `settings.switchBackfillPageOn === true` 且 `settings.observe === true`（切换识别依赖 attach/MO；暂停观测不新开窗口）；
  - `!state.dead`。
- 首次挂载（`fromSid` 为空）不写；同一会话重新挂载（sid 未变）不写；`draft`/空白首屏不写。
- 150ms 内 A→B→A 快速往返：按最后一次真实 sid 变化重置窗口；不新增伪切换记录。
- 窗口长度 `SWITCH_BACKFILL_WINDOW_MS = 30000`；使用 `performance.now()` 域，暂停观测期间继续走表，过期自然失效。
- 不在切换瞬间扫 DOM、不读几何、不加监听器；只写一个时间戳。

### 4.2 包装器安装

- `loadOlder` 包装安装条件扩展为：`settings.scrollDiagOn || settings.loadOlderPaceOn || settings.switchBackfillPageOn`，且 `!state.dead && store`。
- sid 变化后的立即安装条件（`applyThrottle()` 调用点）与 5s 看门狗条件同样加入 `settings.switchBackfillPageOn`。
- 只包当前主 store **实例**的 `loadOlder`；不碰共享原型；marker 仍记录 `{orig, wrapped, gen}`，代际不一致时旧 wrapper 直通。
- 只开本项、关滚动诊断与降频时，包装仍必须装上并生效。

### 4.3 何时用 120 行

`callOrig(self, args)` 内按顺序判断，全部满足才用 120：

1. `settings.switchBackfillPageOn === true`；
2. `!state.dead`；
3. `args.length === 0`（调用方没有传参数；显式 `loadOlder(60)` / `loadOlder(200)` / `loadOlder(undefined)` 一律原样直通）；
4. `switchBackfillAt > 0` 且 `performance.now() - switchBackfillAt <= SWITCH_BACKFILL_WINDOW_MS`；
5. `readLoadedRows(self)` 返回数字，且 `rows <= SWITCH_BACKFILL_MAX_ROWS`（3000）；行数不可读或已超过 3000 时直通，不猜。

命中时：

```
pageStats.applied++;
return orig.call(self, 120);
```

未命中但开关开、无参时：

```
pageStats.passthrough++;
return orig.apply(self, args);
```

显式参数调用不计入 `applied/passthrough`。

### 4.4 语义保持

- 必须保留：`this`、返回的 Promise 引用（不是 `.then` 新包）、同步异常原样抛出、异步失败不吞、`loadingOlder` / `canLoadOlder` 不被修改、返回内容不被改写。
- 不跳过任何调用；120 行由宿主按正常路径合并、更新快照。
- 与 O3 同时开：O3 的跳过判定先执行；被跳过时不调用原方法、不计 `switchPage`、不消耗 120 行页。放行的调用再按 4.3 判 120。
- 暂停观测时：
  - 已开的窗口仍生效并继续计数（与 O3 缓解语义一致）；
  - 不新开窗口（MO 已断开），窗口继续走表并可过期；
  - 不写 `loadOlderDetail`、不上报样本；恢复后继续。
- `scrollDiagOn=false` 不影响本实验；`switchDiagOn=false` 也不影响本实验（只要 `observe=true` 能发现 sid 变化）。

## 5. 计数与样本

### 5.1 `switchPage` 样本字段

只在 `switchBackfillPageOn === true` 时上报，关闭为 `null`；暂停观测时样本同样为 `null`（计数仍继续累加，可通过诊断入口查看）：

```
switchPage = {
  limit: 120,
  applied: <number | null>,
  passthrough: <number | null>,
  installed: <boolean>,
}
```

- `applied`：真正用 120 调用原方法的次数；异步失败也算一次尝试，不按成功数统计。
- `passthrough`：开关开、无参，但窗口过期/行数 >3000/行数不可读，按原样调用的次数。
- `installed`：包装是否装上；`false` 时 `applied/passthrough` 为 `null`，不可用，不伪装成 0。
- 计数对象随包装器生命周期（`wrapped.__lagfixSwitchPage`）：关→开、换 store、自禁用、`__lagfixOff()` 清零；暂停观测不清零。
- 计数在包装器入口更新，不受 `observe`/`scrollDiagOn` 影响；观测只决定是否上报与写明细。

### 5.2 `loadOlderRows30s`（只读）

- 切换记录新增公开字段 `loadOlderRows30s`：切换后 30 秒内成功补页实际增加的行数合计。
- 在 `recordLoadOlderDetail(entry)` 调用 `accumSwitchLoadOlder` 时，若 `entry.ok` 且 `rowsBefore/rowsAfter` 都是数字，累加 `max(0, rowsAfter - rowsBefore)`；非数字按 0，不猜。
- 内部记录字段 `loRows30s: 0`；`switchPublic()` 输出 `loadOlderRows30s`。
- 旧样本没有该字段：报告显示 `-`，不回退成补页次数或 0。

## 6. 报告

新增 `print_switch_page(rows)`，在 `print_switch_diag(rows)` 之后调用：

- 开关开且 `installed=true`：
  - `切换回填页（实验，窗口 <win>）：每页 120 行；按 120 请求 X 次 / 按原样 Y 次`
  - 若 `applied=0`：提示「当前包装周期内还没有按 120 的请求（换 store 或关→开会清零）；确认切换前后都是真实会话、已载行数 ≤3000，且 30 秒内发生过无参补页」。
- 开关开但 `installed=false`：提示「包装未装上，计数不可用」。
- 开关关：提示「已关闭」。
- 旧样本没有 `switchPage`：提示「本版本未记录切换回填页（v0.4.4 前的旧样本）」。
- 自禁用：必须在开关判断之前识别 `dead`，提示「观测器已自禁用；切换回填页计数不可用」；不能因为自禁用时内存开关已置 false 就误报「已关闭」。
- 只描述最新样本所在窗口；多窗口 A/B 必须在同一窗口内完成，报告行会带窗口 id。
- 切换段每条的 30s 补页输出改为：`补页 N 次 / R 行 / Xms`，R 来自 `loadOlderRows30s`；旧样本无 R 时显示 `-`，不回退成补页次数或 0。
- 报告尾部版本摘要更新为 v0.4.4，并说明本实验默认关闭。

## 7. 安全与清理

- 硬红线不变：不读写 `~/.zcode/cli/db.sqlite`，不读会话正文/提示词/回复/工具参数，不开 CDP，不联网上报；不删除用户会话或日志。
- 只包当前主 store 实例，不覆盖共享原型；宿主运行期替换 `loadOlder` 时，旧 wrapper 代际直通，释放只还原本插件那一层。
- `__lagfixOff()`：
  - `settings.switchBackfillPageOn = false`；
  - 清 `switchBackfillAt`、`switchPageStats`（applied/passthrough）；
  - 按现有 `releaseLoadOlderProbe()` 规则还原包装；
  - 面板行取消勾选，样本 `switchPage=null`。
- observer 自禁用：同上（`settings.switchBackfillPageOn` 只在内存置 `false`，不落盘），清窗口与计数。
- 关闭开关：立即停止 120 行行为；计数清零（下一次关→开从 0 起算）；包装仅在 `scrollDiagOn || loadOlderPaceOn` 仍需要时保留。
- 不新增 DOM 属性、不新增全局监听器、不用 `setTimeout` 兜底猜测同步完成。
- 已知边界：宿主替换 store 实例且 sid 未变化时，`installed` 最多可能滞后到下一次 5s 看门狗重装；A/B 每轮仍以 `switchPage.installed=true`、`applied>0` 与当前切换记录为准。

## 8. 测试要求

`tests/observe_smoke.mjs` 至少覆盖：

1. 默认 `switchBackfillPageOn=false`，无参调用原方法收到 0 个参数，样本 `switchPage=null`。

4. 30 秒窗口过期（用测试钩子前移 `switchBackfillAt` 或等待）→ 无参调用收到 0 个参数，`passthrough` +1。
5. 行数 >3000 → 0 个参数，`passthrough` +1；行数不可读（`rows.window` 非数组/长度非数字）→ 0 个参数。
6. 首次挂载（from 为空）不生效；`draft` / 空 sid 切换不生效。
7. 只开本项、`scrollDiagOn=false`、`loadOlderPaceOn=false` 时包装仍装上并生效。

13. `loadOlderRows30s` 在成功补页后按 `rowsAfter - rowsBefore` 累加；失败/非数字不计。
14. 面板行存在、默认不勾选、切换后持久化；用变异验证确认 `v === true` 路径真的写入。

## 9. A/B 验收

控制变量：

- 同一会话、同一段历史、同一滚动路径；
- `observe=true`、`switchDiagOn=true`、`scrollDiagOn=true`；
- `loadOlderPaceOn=false`（隔离 O3）；
- `turnContentVisOn` 保持固定；
- 只切 `switchBackfillPageOn`；关 → 开 → 关至少 3 轮；A/B 期间不暂停观测。

主指标（用切换记录，按每 1000 行归一化）：

- `callsPer1kRows = loadOlderN30s / loadOlderRows30s * 1000`，下降 ≥30%（目标约 -50%）。
- `msPer1kRows = loadOlderMs30s / loadOlderRows30s * 1000`，下降 ≥20%，或滚动 P95 / 长任务下降 ≥10%。

护栏：

- 切换后 2s 最重帧/P95 不退化 >10%；
- 帧 P95 / ≥50ms 长任务不退化 >10%；
- 顶部空白 ≤300ms；
- 锚点漂移 ≤48px；
- DOM 峰值增加 ≤20%；
- `loadOlder` 失败 0，observer errs 不增加。

每轮必须 `switchPage.installed=true` 且 `applied>0`，否则该轮无效并重做。任一门禁未过：默认保持关闭，发布说明如实写「未达门槛」；归一化调用次数没有明显下降则退役，不靠调参续命。
