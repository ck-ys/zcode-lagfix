# v0.3.9 行为规格：设置面板滚动/焦点与还原边界

- 版本：0.3.9
- 日期：2026-11-12
- 范围：设置面板重建时的滚动与焦点、模态焦点管理、`restoreTarget` 还原安全、更新状态文案
- 拍板：用户确认按推荐范围启动；不改变 `__lagfixOff()` 的既有语义（仍保留观测、角标与 Ctrl+Alt+L 入口）

## 1. 产品规则

### 1.1 面板重建保留滚动位置

- 设置面板 `.dlg-content` 是唯一滚动容器；任何触发 `rebuildPanel()` 的开关在重建后必须回到原滚动位置。
- 实现：重建前读取旧内容区 `scrollTop`，重建后写回新内容区；不改变分区（`panelNav`）与开关值。
- 若旧内容区不存在，按 0 处理；新内容区不存在时不抛错。

### 1.2 打开面板时接管键盘焦点

- 首次打开面板（`state.panelOpen` 从 false → true）时记录当前焦点元素，并把焦点移到面板容器（`tabindex="-1"`，不显示焦点框）。
- 面板打开期间 Tab/Shift+Tab 必须在面板内循环，不能把焦点送回宿主 composer；面板内没有可聚焦控件时保持面板焦点。
- 关闭面板时，如果记录的原焦点元素仍连接在文档中，焦点还给它；否则不强制聚焦。
- 通过齿轮或 Ctrl+Alt+L 打开都适用；`rebuildPanel()` 重建时不清空“打开前焦点”，重建后优先恢复同一序号的可聚焦控件，恢复不了则聚焦面板容器。

### 1.3 `restoreTarget` 只还原自己装的那层

- `subscribe` 包装记录 `{ orig, wrapped }`；还原时只有当 `target.subscribe === wrapped` 才写回 `orig`。
- 宿主在插件运行期间替换了 `subscribe` 时，插件不得覆盖宿主的新实现；标记属性可以删除。
- `__lagfixOff()`、关闭「合并刷新」、observer 自禁用三条路径共用该规则。

### 1.4 订阅回调异常留痕

- 合并刷新包装在调用宿主 listener 时如果抛错，仍不向宿主冒泡，但每个页面生命周期最多打印一次 `console.error`，避免完全静默。
- 不把异常内容写入 `observe-*.jsonl`，不改变采样与开关状态。

### 1.5 更新状态文案

- 当检查成功且 `newer=false`，但当前版本高于最新 Release 时，状态行显示「当前 vX 高于最新发布 vY（发布通道尚未更新）」，不显示红点。
- 当前版本等于或低于最新 Release 时，保持原有「已是最新（vX）」。
- 该文案只影响维护页展示，不改变红点判定。

### 1.6 `__lagfixOff()` 边界（保持原语义）

- `__lagfixOff()` 仍只关闭缓解项与诊断项，保留观测、角标、rAF 与 Ctrl+Alt+L/storage/resize 入口；这是 v0.3.0–v0.3.2 已拍板行为，不在本版改成“完全卸载”。
- 本版只修 `restoreTarget` 的覆盖风险，不改变 `__lagfixOff()` 对观测资源的选择。

## 2. 状态与接口

- 新增内部变量：`lastFocusBeforePanel`、内容区固定 id `lagfix-panel-content`。
- 不新增用户设置项，不改变 `localStorage["lagfix.settings.v1"]` 结构。
- 不新增宿主包装、DOM 属性或网络请求。

## 3. 验收场景

`tests/observe_smoke.mjs` 必须覆盖：

1. 面板滚到非 0 后点击会触发 `rebuildPanel()` 的开关，重建后 `.dlg-content.scrollTop` 保持原值。
2. 首次打开面板后 `document.activeElement` 是面板容器；关闭后焦点回到打开前元素。
3. `restoreTarget` 在宿主替换 `subscribe` 后不覆盖新实现；仍是我们自己的 wrapper 时正常还原。
4. 订阅 listener 抛错只打印一次，不影响后续通知。
5. 更新状态：`current > latest` 时显示“高于最新发布”，不显示红点；`current === latest` 保持“已是最新”。
6. 原有 `__lagfixOff()` 用例继续通过：观测保留、角标/面板入口保留。

实机复核：

7. 打开设置 → 性能，滚到底部，连续切换三个开关，页面不跳顶、焦点不丢到宿主输入框。
8. 光标在 composer，按 Ctrl+Alt+L 打开设置，直接输入文字不会进入聊天框；Tab 只在面板内移动；Esc 关闭后焦点回到 composer。
